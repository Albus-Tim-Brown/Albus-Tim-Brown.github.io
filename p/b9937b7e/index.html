Hyper-V安装Windows 11 24H2虚拟机及常见问题

发表于2025-04-27|更新于2026-02-25|Windows虚拟机
|总字数:1.4k|阅读时长:4分钟|浏览量:

前言

注意，此篇内容使用的虚拟机为Hyper-V虚拟机，与其他虚拟机程序无过多关联性，同时对于购买的实体电脑上首次开机时的Windows初始化安装不具有参考性，请分清楚实体电脑首次开机时的Windows初始化安装和虚拟机安装。

由于微软强制要求Windows 11安装时使用微软账户登录，限制使用本地账户，以下的安装场景可能会存在失效，请参照搜索引擎Windows 11安装使用本地账户或Windows 11安装跳过联网激活中的教程内容，在本章节中特定安装步骤时使用对应方法以本地账户方式进入系统，否则会出现无法正常进入桌面的问题

准备工作

在配置好Hyper-V虚拟机服务器之后，就可以进行虚拟机安装操作，若未配置虚拟机请参照本博客中**此篇博文**配置虚拟机环境。

获取Windows镜像

请注意，不推荐从非官方途径获取Windows镜像文件，为避免出现其他问题，本教程中均使用官方最新的Windows 11简体中文镜像文件。

浏览器搜索Windows 11 iso，找到如下的一个界面，如果没有找到，请更换搜索引擎，比如使用Bing搜索：

进入界面，显示这样的内容：

往下拉，直接看到第三个方式，选择下载适用于 x64 设备的 Windows 11 磁盘映像 (ISO)底下的选择“下载”下拉框，选择Windows 11（适用于x64设备的多版本ISO):

选择产品语言选择中，选择简体中文，如果有使用其他语言需要可以选择其他语言：

选择完成语言之后，勾选底下的64位 下载就可以下载对应的镜像文件：

下载完成后，会获得一个iso文件，此文件可以用于实体新机或虚拟机安装最新版本的Windows 11、可以用于当前实体电脑更新Windows版本、也可以用于重装系统。

创建虚拟机

使用Windows搜索栏搜索Hyper-V 管理器并打开，连接到本地或另一台计算机的虚拟服务器。

如果是用来进行虚拟机相关测试，建议直接使用本地的虚拟服务器。

不使用快速创建

在完成**此篇博文**中Hyper-V相关配置后，选择右边栏选项卡中的新建选项，选择新建虚拟机，此时，虚拟机新建向导将会一步步告诉你如何创建以及当前虚拟机的相应配置，按照自身需求完成对应配置：

此处虚拟机的代数选择为第二代，不推荐使用第一代虚拟机：

Windows 11需要的内存大小最低为4GB，此处更推荐开启动态内存：

此处配置网络在虚拟机初始化安装Windows的时候选择为未连接状态，

Windows 11需要的磁盘大小为大于等于64GB，此处可对虚拟磁盘的其他选项进行修改：

此处选择从可启动的 CD/DVD-ROM 安装操作系统，选择媒体底下的映像文件，文件地址选择先前下载的Windows 11 iso文件的地址：

创建完成后，即可启动虚拟机进入虚拟机初始化和Windows安装界面

使用快速创建

如果使用快速创建选项，则会自动进行配置，不推荐从左侧栏选择操作系统中下载

此时选择更改安装源，依旧选择你下载的Windows 镜像文件，请注意更改底部的名称以及更改网络为无网络：

选择创建虚拟机，此时会快速的完成初始化以及虚拟磁盘的创建：

配置虚拟机

此时可以选择编辑设置，查看和编辑调整虚拟机配置，在满足Windows 11安装条件的情况下，可以更改内存大小和处理器个数，以适应自身主机的情况；可以添加硬件用于特定用途或操作；启动顺序已经在你先前创建虚拟机的安装源配置中自动帮你设置为DVD驱动器启动，这实际上是启动了你的镜像文件：

此处需要注意，Windows 11安装的要求中，需要有受信任的平台模块（TPM），需要在安全选项卡中，在加密支持一栏勾选启用受信任的平台模块：

（推荐）在管理选项卡的集成服务中，在服务中勾选来宾服务，可以在一定程度上提高虚拟机访问的便捷性：

初始化Windows安装

在完成虚拟机创建和配置之后，就可以连接虚拟机了，此时由于虚拟机还未开机，会出现如下的界面：

直接点击启动，此时虚拟机开机，开机后会出现一行**”Press any key to boot from CD or DVD…”**，

然后就迅速显示为如下界面：

不要慌张，点击当前窗口下的此处按键：

此时，界面会重置，回到**”Press any key to boot from CD or DVD…”**这个界面。在这个界面中，鼠标可以放入虚拟机中，当出现”Press any key to boot from CD or DVD…”这行文字时，立刻按任意键盘按键，当出现如下字样的内容则代表成功进入：
