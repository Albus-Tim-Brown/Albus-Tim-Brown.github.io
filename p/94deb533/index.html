Windows 11 24H2配置Hyper-V虚拟机服务以及常见问题

发表于2025-04-27|更新于2026-02-25|Windows虚拟机
|总字数:1.2k|阅读时长:3分钟|浏览量:

前言

此文章的演示环境为Windows 11 24H2系统，虚拟机程序需要多核心处理器以及消耗较大的内存和硬盘存储空间，请确保你的运行环境能够正常的运行虚拟机。Hyper-V虚拟机不推荐用于游戏多开、模型渲染、视频剪辑等场景，若强行使用可能会因为性能不足而效率大打折扣，对于网络游戏应用可能会因为厂商的虚拟机检测功能导致有游戏账户被封禁的风险。

准备工作

请注意，以下的部分内容存在时效性，部分内容与你当下的环境可能已经存在差异，请根据本文更新时间来判断此部分内容的时效性，或参照微软官方内容：Windows Server 上的 Hyper-V 的系统要求 | Microsoft Learn

虚拟化支持

在安装虚拟机前，请先确定CPU是否支持虚拟化，可通过如下方式确认（以下以Windows 11的新版任务管理器界面为参考）：

右键Windows开始菜单或任务栏，打开任务管理器，侧边栏选择性能，选择CPU。此时，CPU界面内虚拟化字样显示为已启用则代表CPU已经启用了虚拟化。如果为已禁用，请根据自身设备的具体情况，更改主板BIOS设置以启动虚拟化。搜索引擎搜索方式参考（此处华硕、和联想品牌为举例，请以自身设备具体品牌为准）：华硕主板开启CPU虚拟化支持，联想笔记本开启CPU虚拟化支持等。

Hyper-V支持

Windows 家庭版不支持Hyper-V 虚拟化，且强行开启支持会出现一些问题，建议使用Windows 专业版或专业工作站版本。非企业内部使用、非企业集中采购、非接入企业网络、非公用电脑等仅个人学习或测试使用的电脑，可以使用KMS工具切换和激活Windows专业版或专业工作站版（如果已经是专业版或专业工作站版则无需再次激活）。

如需了解自身设备是否为对应正确的版本，可打开设置，选择左侧栏的系统选项卡，找到最底下系统信息，在底部Windows规格中显示的版本即为对应信息：

满足Windows版本要求后，请参照如下方式检查是否开启Hyper-V：

打开开始菜单或直接使用Windows任务栏的搜索框功能，搜索启用或关闭Windows功能：

找到Hyper-V、虚拟机平台（或Virtual Machine Platform）并勾选，如果已经勾选则维持现状。

勾选完成后点击确定，此时Windows将会下载所对应的依赖。等待下载完成后，提示要重启电脑，按要求重启电脑。

重启电脑之后，打开开始菜单或直接使用Windows任务栏的搜索框功能，搜索Hyper-V，此时如果出现Hyper-V 管理器则代表安装成功。

如果没有出现，则检查前面的步骤是否完成，比如Windows版本是否为非家庭版、是否启用虚拟化、是否正确开启Windows功能中的具体选项等。

虚拟机相应配置

打开Hyper-管理器，若显示为如下图片中的样式，则选择右边栏中Hyper-V管理器下的连接到服务器：

点击连接到服务器后，会弹出一个选项卡：

一般情况下直接选择本地计算机即可，如果你希望连接到你当前网络环境中其他的计算机，可以选择另一台计算机。

连接到虚拟机服务器之后，右侧栏将会显示当前虚拟机服务器的操作，包括设置虚拟机，导入虚拟机，创建虚拟机、交换机等：

点击右边栏Hyper-V设置，可以根据自身需求进行更改对应设置：

此处的服务器下拉列表可以更改Hyper-V虚拟机磁盘以及配置文件的存放位置，由于虚拟机一般占用空间较大，建议更改到其他驱动器中；其他选项，诸如增强会话策略建议为开启状态，可以一定程度上增加Hyper-V虚拟机的操作方便性，具体可以参考：与 Windows 虚拟机共享设备 | Microsoft Learn。

此处的用户下拉列表中，可以更改在虚拟机连接并处于前台时，键盘快捷键优先响应主机还是虚拟机，推荐更改为仅当全屏幕运行时在虚拟机上使用；启用增强会话模式可以一定程度上增加Hyper-V虚拟机的操作方便性。
